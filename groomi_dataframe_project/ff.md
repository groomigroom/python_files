실무에서 흔히 쓰이는 딕셔너리 형태로 데이터를 만들어 데이터프레임(DataFrame)을 생성합니다. [1]

## 2. 데이터 가공 (총 매출액 계산하기)
수량과 단가를 곱한 총 매출액(총매출) 컬럼을 새로 추가합니다.

# 수량 * 단가 연산
df['총매출'] = df['수량'] * df['단가']
print(df)

------------------------------
## 3. 데이터 그룹화 및 집계 (groupby)
카테고리별로 총 판매 수량과 총 매출액을 합산합니다. [2] 

# 카테고리별 그룹화 후 합계 구하기category_sales = df.groupby('카테고리')[['수량', '총매출']].sum()
