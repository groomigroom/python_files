이 화면은 JupyterLab(또는 최신 버전의 Jupyter Notebook 7+)의 설정(Settings) UI입니다.
화면에 보이는 Code Cell Configuration 항목에서 Auto Closing Brackets 체크박스를 클릭하여 활성화하시면 됩니다.
설정하는 구체적인 순서는 다음과 같습니다.
## 설정 방법

   1. 현재 열려 있는 설정 화면의 오른쪽 본문에서 Code Cell Configuration 섹션을 찾습니다.
   2. Auto Closing Brackets 왼쪽에 있는 빈 체크박스를 클릭하여 체크(V)합니다.
   3. 체크하는 즉시 설정이 자동으로 저장 및 적용됩니다.
