네, 구글 코랩(Google Colab)에서도 Flask를 사용할 수 있습니다.
다만 코랩은 개인 PC(로컬 환경)가 아니라 구글의 원격 가상머신에서 실행되기 때문에, 일반적인 localhost:5000 주소로는 웹사이트에 접속할 수 없습니다. 대신 외부 주소(Unal)로 연결해 주는 터널링 도구를 함께 사용해야 합니다.
가장 쉽고 안정적인 2가지 방법을 소개해 드립니다.
------------------------------
## 방법 1. pyngrok 라이브러리 사용하기 (가장 확실한 방법)
코랩 내부에서 실행된 Flask 서버를 ngrok이라는 서비스를 통해 외부에서 접속 가능한 임시 URL(https://...)로 만들어주는 방식입니다.
1단계: 라이브러리 설치
코랩 셀에 아래 코드를 입력하고 실행합니다.

!pip install Flask pyngrok

2단계: ngrok 회원가입 및 토큰 설정
ngrok은 무료이지만 가입 후 인증 토큰을 받아야 사용 가능합니다.

   1. [ngrok 홈페이지](https://ngrok.com/)에 회원가입합니다.
   2. 대시보드의 Your Authtoken 메뉴에서 토큰을 복사합니다.
   3. 코랩에 아래 코드를 입력합니다 (토큰 입력 필수).

from pyngrok import ngrok
# 복사한 토큰을 여기에 넣으세요NGROK_AUTH_TOKEN = "여기에_당신의_토큰을_입력하세요"
ngrok.set_auth_token(NGROK_AUTH_TOKEN)

3단계: Flask 코드 작성 및 실행

from flask import Flaskimport threading
app = Flask(__name__)

@app.route("/")def home():
    return "<h1>구글 코랩에서 실행된 Flask 서버입니다!</h1>"
def run_app():
    # 코랩 환경에서는 debug=True를 쓰면 충돌이 날 수 있어 False로 설정합니다.
    app.run(port=5000, debug=False, use_reloader=False)
# Flask를 백그라운드 스레드에서 실행
threading.Thread(target=run_app).start()
# ngrok 터널을 열어 외부 접속 주소 생성public_url = ngrok.connect(5000)
print("이 주소로 접속하세요:", public_url)

출력된 NgrokTunnel: "https://ngrok-free.app" 형태의 링크를 누르면 웹페이지가 열립니다.
------------------------------
## 방법 2. 코랩 자체 내장 기능 사용하기 (가장 간단한 방법)
라이브러리 설치나 가입 없이, 구글 코랩이 자체적으로 제공하는 포트 포워딩 기능을 이용하는 방법입니다.
1단계: Flask 설치 및 실행

!pip install Flask
from flask import Flaskimport threading
app = Flask(__name__)

@app.route("/")def home():
    return "<h1>가입 없이 띄우는 Flask 서버</h1>"
# 백그라운드에서 Flask 실행 (포트는 8000번 추천)
threading.Thread(target=lambda: app.run(host="0.0.0.0", port=8000, debug=False, use_reloader=False)).start()

2단계: 코랩 접속 URL 확인
Flask를 실행한 후, 새 셀에 아래 파이썬 코드를 실행하면 접속 가능한 구글 링크가 생성됩니다.

from google.colab import output# 8000번 포트로 연결되는 외부 주소 출력
print("접속 링크:", output.eval_js("google.colab.kernel.proxyPort(8000)"))

------------------------------
## ⚠️ 코랩에서 Flask 사용 시 주의점

* 실시간 코드 수정 불가: 코드를 수정했다면 웹 브라우저만 새로고침해서는 안 되고, 코랩 셀을 멈췄다가(Stop) 다시 실행해야 적용됩니다.
* 개발/테스트 용도: 코랩 세션이 끊기거나 창을 닫으면 서버도 즉시 종료되므로, 실제 서비스 배포용이 아닌 단순 테스트나 API 프로토타입 확인용으로만 쓰셔야 합니다.

혹시 준비하신 머신러닝 모델을 Flask와 연동해서 입력값을 받고 결과를 리턴하는 API를 짜보고 싶으신가요? 필요하시다면 관련된 간단한 예제 코드를 짜드릴 수 있으니 말씀해 주세요!



import threading
from flask import Flask
from pyngrok import ngrok  # pyngrok 모듈 가져오기 추가

# 1. ngrok 인증 토큰 설정 (필수!)
# 토큰 확인 주소: https://ngrok.com
NGROK_TOKEN = "사용자토큰입력하기!!"
ngrok.set_auth_token(NGROK_TOKEN)

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>구글 코랩에서 열심히 공부해요!</h1>"

def run_app():
    # 코랩 환경 충돌 방지를 위해 debug=False, use_reloader=False 설정
    app.run(port=5000, debug=False, use_reloader=False)

# 2. Flask를 백그라운드 스레드에서 실행
threading.Thread(target=run_app).start()

# 3. ngrok 터널을 열어 외부 접속 주소 생성
# 포트 번호는 문자열 또는 숫자로 지정 가능하며, 프로토콜 명시가 안전합니다.
tunnel = ngrok.connect(5000, "http")
print("이 주소로 접속하세요:", tunnel.public_url)
