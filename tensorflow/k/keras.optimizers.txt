tf.keras.optimizers는 TensorFlow 내에서 인공신경망 모델을 학습시킬 때 가중치(Weight)와 편향(Bias)을 자동으로 수정하여 손실(Loss)을 최소화하는 최적화 알고리즘(Optimizer)들의 모음입니다. [1] 
구조를 나누어 보면 다음과 같은 의미를 가집니다.

* tf: 텐서플로우(TensorFlow) 라이브러리 자체를 가리킵니다.
* .keras: 텐서플로우에 내장된 고수준(High-level) 딥러닝 API인 케라스(Keras) 모듈을 뜻합니다. 개발자가 복잡한 수학식을 직접 짜지 않고도 직관적으로 모델을 만들 수 있도록 돕습니다.
* .optimizers: 딥러닝의 핵심 단계인 '학습(경사하강법 등)'을 담당하는 알고리즘들이 담겨 있는 폴더(패키지)입니다. [2, 3, 4, 5] 

------------------------------
## 💡 왜 최적화 함수(Optimizer)가 필요할까요?
딥러닝 모델은 처음에 무작위(랜덤) 값으로 예측을 시작합니다. 당연히 정답과 틀린 오차(손실, Loss)가 크게 발생합니다. 이때 "정답을 맞히기 위해 가중치를 어느 방향으로, 얼마나 수정해야 하는가?"를 수학적으로 계산하고 적용해 주는 가이드 역할이 바로 최적화 함수입니다. [1, 5] 
## 🛠️ 주로 사용하는 최적화 함수의 종류
tf.keras.optimizers 안에는 데이터와 모델의 특성에 맞게 골라 쓸 수 있는 다양한 알고리즘이 들어있습니다. [5] 

* tf.keras.optimizers.Adam: 현재 딥러닝에서 가장 대중적이고 기본적으로 추천되는 최적화 함수입니다. 계산 속도가 빠르고 방향과 보폭(Learning Rate)을 모두 효율적으로 조절합니다.
* tf.keras.optimizers.SGD: 확률적 경사 하강법이라는 가장 고전적인 방식입니다. 때에 따라 안정적인 학습을 위해 사용됩니다.
* tf.keras.optimizers.RMSprop: 순환 신경망(RNN)이나 시계열 데이터를 다룰 때 자주 쓰이는 알고리즘입니다. [1, 5, 6] 

## 💻 실제 코드에서의 사용 예시
보통 모델을 빌드한 후, 학습 전용 환경을 설정하는 compile 단계에서 지정합니다. [1] 

import tensorflow as tf
model = tf.keras.Sequential([ ... ]) # 모델 정의
# 최적화 함수로 Adam을 지정하고, 한 번에 학습할 보폭(lr)을 설정
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
