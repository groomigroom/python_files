tf.Variable()은 값이 언제든 변할 수 있는 변수(Variable) 텐서를 생성하는 함수입니다.
앞서 보셨던 tf.constant()가 값이 한 번 정해지면 바꿀 수 없는 '상수'라면, tf.Variable()은 딥러닝 모델이 학습하면서 스스로 값을 업데이트(수정)할 수 있는 '변수'를 만듭니다.
------------------------------
## 1. 왜 사용할까? (딥러닝에서의 핵심 역할)
인공지능 모델이 학습한다는 것은 컴퓨터가 정답을 맞히기 위해 내부의 가중치(Weights)와 편향(Biases)을 계속 수정해 나가는 과정입니다.

* 값이 고정된 tf.constant()로는 가중치를 바꿀 수 없습니다.
* 따라서 딥러닝 모델의 가중치처럼 자동으로 업데이트되어야 하는 값들은 반드시 tf.Variable()로 선언해야 합니다.

## 2. 기본 사용법과 값 수정하기
tf.Variable()로 만든 변수는 파이썬의 대입 연산자(=)로 값을 바꿀 수 없습니다. 대신 .assign() 이라는 특수한 메서드를 사용해야 합니다.

import tensorflow as tf
# 초기값 3.0을 가진 변수 생성
구름이 = tf.Variable(3.0)
print("처음 값:", 구름이.numpy()) # 출력: 3.0
# 텐서플로 변수 값 변경 (assign 사용)
구름이.assign(5.0)
print("변경된 값:", 구름이.numpy()) # 출력: 5.0
# 기존 값에 더하기 (assign_add 사용)
구름이.assign_add(2.0)
print("더해진 값:", 구름이.numpy()) # 출력: 7.0

## 3. tf.constant() vs tf.Variable() 한눈에 보기

| 특징 | tf.constant() (상수) | tf.Variable() (변수) |
|---|---|---|
| 값의 변경 | 불가능 (고정됨) | 가능 (.assign() 활용) |
| 주요 용도 | 입력 데이터, 이미지, 정답 레이블 등 | 모델의 가중치(W), 편향(b) 등 |
| 메모리 특징 | 한 번 생성되면 메모리 구조 고정 | 값이 바뀌어도 메모리 주소 유지 |

------------------------------
이제 텐서플로의 가장 기본적인 3가지(상수 constant, 연산 add/cast, 변수 Variable)를 모두 파악하셨습니다!
