tf.Variable()은 값이 언제든 변할 수 있는 변수(Variable) 텐서를 생성하는 함수입니다.
앞서 보셨던 tf.constant()가 값이 한 번 정해지면 바꿀 수 없는 '상수'라면, tf.Variable()은 딥러닝 모델이 학습하면서 스스로 값을 업데이트(수정)할 수 있는 '변수'를 만듭니다.
------------------------------
## 1. 왜 사용할까? (딥러닝에서의 핵심 역할)
인공지능 모델이 학습한다는 것은 컴퓨터가 정답을 맞히기 위해 내부의 가중치(Weights)와 편향(Biases)을 계속 수정해 나가는 과정입니다.

* 값이 고정된 tf.constant()로는 가중치를 바꿀 수 없습니다.
* 따라서 딥러닝 모델의 가중치처럼 자동으로 업데이트되어야 하는 값들은 반드시 tf.Variable()로 선언해야 합니다.

## 2. 기본 사용법과 값 수정하기
tf.Variable()로 만든 변수는 파이썬의 대입 연산자(=)로 값을 바꿀 수 없습니다. 대신 .assign() 이라는 특수한 메서드를 사용해야 합니다.

import tensorflow as tf
# 초기값 3.0을 가진 변수 생성
구름이 = tf.Variable(3.0)
print("처음 값:", 구름이.numpy()) # 출력: 3.0
# 텐서플로 변수 값 변경 (assign 사용)
구름이.assign(5.0)
print("변경된 값:", 구름이.numpy()) # 출력: 5.0
# 기존 값에 더하기 (assign_add 사용)
구름이.assign_add(2.0)
print("더해진 값:", 구름이.numpy()) # 출력: 7.0

## 3. tf.constant() vs tf.Variable() 한눈에 보기

| 특징 | tf.constant() (상수) | tf.Variable() (변수) |
|---|---|---|
| 값의 변경 | 불가능 (고정됨) | 가능 (.assign() 활용) |
| 주요 용도 | 입력 데이터, 이미지, 정답 레이블 등 | 모델의 가중치(W), 편향(b) 등 |
| 메모리 특징 | 한 번 생성되면 메모리 구조 고정 | 값이 바뀌어도 메모리 주소 유지 |

------------------------------
이제 텐서플로의 가장 기본적인 3가지(상수 constant, 연산 add/cast, 변수 Variable)를 모두 파악하셨습니다!
혹시 이 개념들을 활용해서 y = W * x + b 같은 간단한 선형 회귀(Linear Regression) 모델의 구조를 구경해 보고 싶으신가요?

---------------------------------------------------


numpy() 함수를 사용하는 이유는 텐서플로의 '텐서' 객체를 파이썬에서 다루기 쉬운 일반 '넘파이(NumPy) 배열'로 변환하기 위해서입니다.
쉽게 말해, 텐서플로라는 특수한 틀 안에 갇혀 있는 데이터 알맹이(값)만 쏙 빼내어 화면에 깔끔하게 출력하거나 활용하고 싶을 때 사용합니다.
그 구체적인 이유는 다음과 같습니다.
## 1. 깔끔한 출력 (가독성)
print() 문에 텐서 객체를 그대로 넣으면 텐서의 메타데이터(형태, 데이터 타입 등)가 함께 출력되어 지저분합니다. 반면 .numpy()를 붙이면 데이터 값 자체만 깔끔하게 보여줍니다.

import tensorflow as tf
구름이 = tf.constant([1, 2, 3])

print(구름이)         # 1. 그대로 출력할 때# 출력: tf.Tensor([1 2 3], shape=(3,), dtype=int32)

print(구름이.numpy()) # 2. .numpy()를 사용해 출력할 때# 출력: [1 2 3]

## 2. 다른 파이썬 라이브러리와의 연동
인공지능 모델을 만들 때는 텐서플로만 쓰지 않습니다. 데이터를 그래프로 그려주는 matplotlib이나, 데이터를 표 형태로 다루는 pandas 같은 라이브러리를 함께 사용합니다.
이 라이브러리들은 텐서플로의 Tensor 타입을 이해하지 못하는 경우가 많습니다. 이때 .numpy()로 변환해 전달하면 아무런 문제 없이 작동합니다.

import matplotlib.pyplot as plt
# ❌ 텐서 객체를 그대로 넣으면 에러가 나거나 그래프가 안 그려질 수 있음# plt.plot(구름이) 
# ⭕ 넘파이 배열로 변환해서 전달해야 안전함
plt.plot(구름이.numpy()) 

## 3. 내부적인 동작 원리 (메모리 공유)
사실 .numpy()를 실행할 때 컴퓨터는 데이터를 새로 복사하는 귀찮은 작업을 하지 않습니다. 텐서플로 텐서와 변환된 넘파이 배열은 컴퓨터 메모리 상에서 동일한 주소(메모리 공간)를 공유합니다.
따라서 컴퓨터에 부담을 주지 않고 순식간에 데이터를 주고받을 수 있습니다.
