import numpy as np

def softmax(a):
# 각 요소를 지수화 (e^x)합니다.
exp_a = np.exp(a)
# 지수화된 값들의 총합으로 나눕니다.
return exp_a / np.sum(exp_a)

a = [1.0, 2.0, 3.0]
print(softmax(a))
출력: [0.09003057, 0.24472847, 0.66524096]

소프트맥스(Softmax) 함수에서 np.exp()를 사용하는 이유는 수학적 성질을 이용해 모델의 출력을 완벽한 '확률 분포'로 변환하기 위해서입니다.
단순히 값들의 비율을 구하지 않고, 굳이 지수함수($e^x$)를 씌우는 핵심 이유는 크게 3가지가 있습니다.

───

1. 음수(Minus)를 양수로 만들기 위해 (Non-negativity)
확률은 항상 0 이상 1 이하의 값이어야 합니다. 하지만 인공지능 모델(신경망)이 내뱉는 최종 점수(Logits)는 [-5.2, 0.0, 3.5]처럼 음수가 포함될 수 있습니다.
• 만약 그냥 합으로 나누면 음수 확률이 나오는 말도 안 되는 상황이 발생합니다.
• $e^x$ 그래프를 보면 $x$가 아무리 작은 음수여도 항상 0보다 큰 양수($>0$)가 됩니다. 덕분에 안전하게 확률로 변환할 수 있습니다.
2. 큰 값은 더 크게, 작은 값은 더 작게 (Amplification)
지수함수는 값이 커질수록 기울기가 가파르게 증가하는 특성이 있습니다.
• 입력값 $[1.0, 2.0, 3.0]$의 차이는 각각 $1$씩 일정합니다.
• 하지만 np.exp()를 통과하면 $[2.7, 7.4, 20.1]$이 되어 차이가 극적으로 벌어집니다.결과적으로 가장 높은 점수를 받은 선택지(여기서는 3.0)에 확률을 확실하게 몰아주는(Soft-max) 역할을 합니다.
3. 미분(Gradient) 연산이 매우 깔끔해지기 때문에
딥러닝은 오차역전파(Backpropagation) 과정에서 끊임없이 미분을 계산해야 합니다.
• $e^x$는 미분을 해도 자기 자신인 $e^x$가 되는 독특한 성질을 가집니다.
• 이 덕분에 소프트맥스 함수와 교차 엔트로피(Cross-Entropy) 손실 함수를 결합하여 미분하면, 복잡한 계산이 다 사라지고 (모델의 예측 확률 - 실제 정답)이라는 매우 직관적이고 깔끔한 수식만 남게 됩니다. 컴퓨터가 학습하기에 최적의 조건이 되는 것입니다.

───

⚠️ 실전에서 쓰이는 소프트맥스 보완 팁 (오버플로우 방지)
보여주신 코드는 완벽한 소프트맥스의 정의지만, 실전 딥러닝에서는 한 가지 문제가 발생할 수 있습니다. 입력값 a에 1000처럼 큰 숫자가 들어가면 np.exp(1000)이 무한대(inf)로 발산하여 에러(오버플로우)가 납니다.
그래서 실제 라이브러리나 실전 코드에서는 아래와 같이 입력값 중 최댓값을 빼주는 방식을 사용합니다. 지수함수의 성질 덕분에 모든 값에서 똑같은 수를 빼도 결과는 변하지 않습니다.
python
import numpy as np def robust_softmax(a): c = np.max(a) # 최댓값을 찾아서 exp_a = np.exp(a - c) # 모든 원소에서 빼줍니다. (오버플로우 방지) return exp_a / np.sum(exp_a) a = [1000.0, 1001.0, 1002.0] # 큰 값이 들어와도 print(robust_softmax(a)) # 안전하게 [0.09003057, 0.24472847, 0.66524096] 출력!
